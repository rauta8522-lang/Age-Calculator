# Age Calculator in C

A simple and efficient command-line application built using *C programming* to calculate the exact age of a person.

## 📌 Project Overview
The *Age Calculator* takes the user's date of birth (Day, Month, Year) and the current date as input. It then calculates the total age in terms of *Years, Months, and Days*, handling the logic for different month lengths and leap years.

## 🚀 Features
* Accurate age calculation from any given date of birth.
* Handles different days in months (28, 30, 31).
* Built with a focus on logic building and conditional statements in C.
* Lightweight and fast execution.

## 🛠️ Tech Stack
* *Language:* C Programming
* *Compiler:* GCC (or any standard C compiler)
